# Consulting Deck Planner Knowledge

このフォルダは、`consulting-deck-planner` テンプレート専用の編集用ナレッジ置き場です。

## フォルダの役割

- `00_共通ルール/`: MECE、意思決定、Insight、Recommendation、分析フローなど、企画書全体に共通する判断ルール
- `01_企画書/`: 完成版プロンプト、入力テンプレート、出力フォーマット、章構成、各章、スライド設計
- `02_リサーチ/`: リサーチプロンプト、検索カテゴリ、情報源評価、エビデンス抽出、実行手順
- `04_スライド/`: レイアウト一覧、レイアウト選択、表示内容、文字量、フレームワーク対応
- `05_フレームワーク/`: 3C、SWOT、STP、AARRR、TAM/SAM/SOM
- `99_サンプル/`: 出力サンプル

## 初心者向けの見方

1. まず `01_企画書/00_完成版プロンプト.md` で全体像を確認します。
2. リサーチ条件を変える場合は `02_リサーチ/` を編集します。
3. スライドの見せ方を変える場合は `04_スライド/` を編集します。
4. 分析フレームワークを増やす場合は `05_フレームワーク/` にMarkdownを追加します。
5. 共通判断ルールを変える場合は `00_共通ルール/` を編集します。

## 実行時参照との関係

現在のランナーは `references/` 配下の軽量ファイルを直接読みます。
`knowledge/` は、人間が編集しやすい詳細資料・元資料として管理します。
