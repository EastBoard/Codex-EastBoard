
# スライドレイアウト設計方針

## 結論

テーマ別にレイアウトを作るのではなく、論理役割別にレイアウトを固定する。

## 理由

テーマは無限にあるため、テーマ別レイアウトでは破綻する。一方、企画書で伝える論理役割は比較的固定化できる。

## 論理役割

- 表紙
- 要約
- 章全体像
- 要点整理
- 比較
- 課題整理
- 原因分析
- 因果関係
- プロセス
- 時系列
- KPI
- 推移
- 構成比
- 評価
- 優先順位
- フレームワーク整理

## 実装原則

- layout_id を固定する
- JSON Schema を固定する
- title_max / body_max を守る
- max_items を超えたら分割する
- データがない場合は chart 系にしない
